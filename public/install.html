📌 pagebot
  1. Show your bookmarks bar (Ctrl+Shift+B / Cmd+Shift+B) and drag the button above onto it.
  2. On any page, click the bookmark. Click again to hide/show.
  3. Enter your password once per site; it's remembered after that.
  4. 📄 sends the page text, 📷 grabs a screenshot (Chrome asks to share the tab the first time per page), or paste any image.

Can't drag? Make a new bookmark and paste this as the URL:

Some sites block overlays; on those the bookmark shows an “Open pagebot” button that opens it in a small window instead. Manage the password and see token usage at /admin.
